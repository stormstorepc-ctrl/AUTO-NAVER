# Chrome 확장으로 상품 가져오기

사용자 결정(2026-11-08, Claude 채팅에서 직접): "Chrome 확장 방식 진행". 제안 출처: PR #9 ChatGPT 댓글 6709406967, 이슈 #15.

## 동작
1. 사용자가 자기 Chrome에서 타오바오/티몰 상품 페이지를 연다. 로그인·보안 확인은 사용자가 직접 한다.
2. 옵션을 누르고(선택한 옵션 가격만 가져옴), 확장 아이콘 → "이 상품 가져오기".
3. 확장(`chrome_extension/`)이 **그 탭만** 읽는다(`activeTab` + `scripting`, 사용자 클릭 때만 권한 부여):
   제목, 화면의 가격 문구 원문, 선택된 옵션, 대표/상세 이미지 주소(lazy-load·srcset 포함, 150px 미만 아이콘 제외).
   로그인/보안 확인 화면이면 보내지 않고 안내한다.
4. 확장은 `http://127.0.0.1:8765/capture`로만 보낸다(`host_permissions`). 연결 코드(`X-Capture-Token`) +
   `chrome-extension://` Origin + loopback + 512KB 제한 + 엄격한 형식 검사. 쿠키·비밀번호는 읽거나 보내지 않는다.
5. 검토 프로그램 `/capture/{번호}`에서 가격(제안값)·옵션 이름·이미지 체크·배송기간·판매 가능 확인 → "확인하고 저장".
   같은 상품을 다른 옵션으로 다시 가져오면 옵션이 추가된다. 선택하지 않은 옵션 가격은 추측하지 않는다.

## 설치
`/capture` 화면 안내: chrome://extensions → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다" → `chrome_extension` 폴더 →
아이콘 고정 → 연결 코드 붙여넣기·저장. 연결 코드는 DB `settings` 테이블에 저장되고 감사 로그에는 남기지 않는다. 화면에서 새로 만들 수 있다.

- **미검증**: 실제 타오바오/티몰 페이지 구조(Claude 환경에서 접속 차단) — 클래스 이름 추정 기반이라 실제 페이지에서 일부 항목을 못 찾을 수 있다.
  실제 버튼 클릭(activeTab 부여)은 자동화할 수 없어 사용자 PC에서 확인해야 한다. Windows 미검증.
