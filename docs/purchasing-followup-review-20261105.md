## 수정한 동작

1. 현재 옵션 원가·식별자와 견적 원본을 대조한다. 원가 변경 후 오래된 견적으로 재승인할 수 없다.
2. 번역 source_hash와 현재 제목·설명·옵션 원문을 대조한다. 원문 변경 후 이전 번역 검수 상태를 재사용할 수 없다. 새 번역 검수·재견적 후 정상 재승인되는 경로도 테스트했다.
3. CSV의 같은 상품 공통 정보가 옵션 행마다 충돌하면 그룹을 거부한다. 후속 행의 판매 제한 정보가 사라지지 않는다.
4. 제한 플래그 원소 타입을 검사하여 잘못된 상품만 거부하고 정상 상품은 계속 가져온다.
5. 가져온 원가의 비용 6개 항목이 누락되면 가격 확정을 보류한다. 명시한 0원은 유효한 값으로 처리한다. 각 비용 항목을 하나씩 제거하는 테스트를 추가했다.
6. 기존 판매가 평가에도 누락/만료된 채널 수수료 검사를 적용한다.
7. 게시 요청 처리 중 조회 결과가 비어도 unknown을 유지한다. 지연된 첫 요청이 완료될 수 있는 동안 두 번째 등록 요청을 보내지 않는다. 모의/실제 어댑터의 복구 대상을 분리한다.
8. 시스템 시간대 DB 없는 환경에서도 주간 실행할 수 있도록 tzdata를 추가하고 해당 조건에서 CLI를 실행했다.
9. Windows 종료 명령은 포트 번호만 보고 다른 프로세스를 강제 종료하지 않도록 가상환경 Python 경로·앱 명령을 확인한다.
