# 주소로 상품 추가 · Claude 번역 도우미

사용자 선택(2026-11-06): 1번 상품 가져오기를 쉽게 + 2번 (가) 무료 복사·붙여넣기 번역.

## 방식
- 이 프로그램은 타오바오에 직접 접속하거나 자동 수집하지 않는다. 사용자가 자기 Chrome에서 연 상품 페이지의 글을 복사해 붙여넣는다.
  (자동 수집은 타오바오 이용 조건·로그인·자동화 차단 문제가 있고, 개발 환경에서 타오바오 접속이 막혀 검증할 수 없었다.)
- 프로그램이 Claude 요청 문구를 만들고, 사용자가 Claude 채팅에 붙여넣어 받은 JSON 답변을 다시 붙여넣는다. 유료 API는 쓰지 않는다.
- 상품 번호와 주소는 사용자가 넣은 타오바오/티몰 주소에서만 가져온다. 답변에 다른 ID나 주소가 있어도 무시한다.
- 답변은 기존 `validate_product` 검증을 그대로 거친다. 가격이 없는 옵션은 거부한다. 무게는 비어 있어도 되며 가격 계산 화면에서 입력한다.
- 판매 가능 확인 체크를 하지 않으면 저장은 되지만 승인 단계에서 차단된다.
- 번역 답변은 모든 옵션 ID가 있어야 저장되고, 초안으로만 저장된다. 사람이 원문과 대조해 검수 완료를 눌러야 한다.

## 화면
- `/import/url`: 주소 + 페이지 글 → 요청 문구 → 답변 붙여넣기 → 상품 저장
- 상품 화면의 "Claude로 번역하기": 요청 문구 → 답변 붙여넣기 → 번역 초안 저장
