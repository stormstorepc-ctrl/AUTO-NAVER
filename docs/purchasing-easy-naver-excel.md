# 간편 설정 · 네이버 일괄등록 엑셀

사용자 결정(2026-11-16, Claude 채팅): 마진은 "수수료를 뺀 뒤 원가의 7%", 나중에 쉽게 바꿀 수 있게.
네이버 양식: 사용자가 올린 `ExcelSaveTemplate_20260324.xlsx` (93열, 1~2행 제목, 3~6행 작성 가이드).

## 가격
`판매가 = (위안 가격 × 환율 + 상품 1개당 추가 비용) × (1 + 마진) ÷ (1 − 판매 수수료)`, 10원 단위 올림.
`/easy` 화면에서 마진·수수료·환율·추가 비용을 저장하면 모든 상품 가격이 다시 계산된다. 값이 비어 있으면 가격을 만들지 않는다.
기존 정밀 가격 엔진(무게·요율·견적 만료·승인)은 그대로 있고, 엑셀은 이 간편 계산을 쓴다.

## 엑셀
- 제목 2행은 양식과 동일(93열·묶음 제목·병합 7개 일치 확인), 상품은 3행부터. 양식의 작성 가이드 행은 넣지 않는다(업로드 전 삭제하라고 안내되어 있음).
- 상품명: 한국어 번역 제목(금지 문자 제거, 100자). 번역이 없으면 그 상품은 제외하고 이유를 보여준다.
- 옵션: 조합형, 옵션명 `옵션`, 옵션값은 번역된 옵션 이름(쉼표 제거, 25자), 판매가는 가장 싼 옵션, 옵션가는 차액.
  차액이 네이버 허용 범위를 넘으면 경고한다.
- 대표이미지 1개 + 추가이미지 최대 9개 + 상세설명(번역 설명 + 이미지 태그). 지금은 원본 이미지 주소를 쓴다(한글화 이미지는 다음 단계).
- 카테고리·원산지 코드, 배송비/A·S 템플릿 코드는 설정값을 넣고, 비어 있으면 "올리기 전 확인할 점"으로 알려준다.
